## Emoji Archive

> 「文件夹里的表情包越囤越多，真正想发的那一张却总在最深处——那就把它们都好好收进来吧！」

这是一款面向日常聊天与表情包收藏的轻量本地管理工具。解决聊天软件表情额度限制、跨软件难同步的痛点，纯本地存储，想存多少存多少。

## 核心特性

- **分类与置顶**：支持多分类归属与拖拽排序；常用表情可单张或批量置顶，**Ctrl+Z** 撤销最近最多 50 步分类变更。
- **窗口与快捷键**：关闭软件默认进到托盘，使用**Alt+`** 唤出/收起，不用一次次去找窗口。
- **悬停动图 & 顺手发**：默认静态预览不卡顿，鼠标悬停播放 GIF / 动态 WebP；单击复制（动图保留动态），~拖出窗口外自动粘贴~；支持窗口置顶与边缘吸附。
- **秒搜与批量**：支持名称、拼音全拼及首字母搜索（中英混合可用）；支持框选/勾选批量加分类、置顶、删除，以及「历史」（最近 50 条复制记录，移出历史不删原图）。
- **备份与外观**：支持按内容 MD5 去重导入、导出/导入 `.zip` 备份；提供深色/浅色/樱花主题、透明度，自定义字体与自定义灵敏度。
- **纯本地离线**：无后端、无联网、无登录，数据全部保存在本地。

## 快速开始

前往 [Releases](../../releases) 下载 `EmojiArchive-<版本>-portable-win64.zip`：

1. 解压到独立文件夹（如 `D:\Apps\EmojiArchive`），**不要直接把 exe 拖到桌面**，以免数据生成在桌面上。
2. 双击 `emoji-archive.exe` 即可运行（免安装）；需要桌面图标可右键创建快捷方式。
3. 若触发 Windows SmartScreen 提示，点击「更多信息 → 仍要运行」。

> **便携说明**：所有数据默认保存在 exe 同级 `data\` 目录，整个文件夹拷走即可迁移；若目录不可写，将自动回退至设置目录、`%LOCALAPPDATA%\EmojiArchive` 或 `local_data`（亦可在「设置 → 数据目录」手动指定）。

## 目录与配置

```text

├── archive.db        # SQLite 数据库（分类、名称、置顶、排序、设置）
├── emojis\           # 原图平铺存储（按 MD5 命名，多分类不重复占原图空间）
├── thumbs\           # 缩略图

软件根目录下的两个可选纯文本配置（修改后重启生效，删掉则回退默认）：

 * welcome.txt：首次启动欢迎页内容（内容变更后会自动再次弹出提示）。
