## 这里能帮你做什么

- **归类与置顶**：建好专属分类，导入时自动归入当前页面；把最常掏出来的「本命表情」置顶，随时一眼锁定。
- **悬停播动图**：默认静态预览不卡顿，鼠标悬停即可播放动图，看清每一帧整活细节。
- **顺手发送**：左键单击复制到剪贴板，到聊天框 Ctrl+V 即可（GIF、动态 WebP 还是动的）；~~也支持直接拖出软件粘贴到聊天框~~（暂未实现）；打开「窗口置顶」，边聊边发更轻松。
- **整理与备份**：支持排序换位、批量添加分类或批量清理，也能随时打包导出 `.zip` 备份，换台电脑也能完整带走。
- **本地离线保存**：分类记录与图片都安稳保存在你的本地数据目录中，清爽、可控、不折腾。

祝你今天也能精准掏出好表情，聊天斗图一路顺风！如果有想调整的顺手小功能，随时记下来慢慢完善就好。

## 下载与使用

到本仓库的 [Releases](../../releases) 页面下载最新的 `EmojiArchive-<版本>-portable-win64.zip`：

1. 解压到任意文件夹（比如 `D:\Apps\EmojiArchive`），**不要只把 exe 拖到桌面**，否则 `data` 会建在桌面上
2. 双击 `emoji-archive.exe` 就能用，不需要安装
3. 想要桌面图标：右键 exe →「发送到」→「桌面快捷方式」
4. 首次运行会弹一页使用说明；若被 Windows SmartScreen 拦下，点「更多信息 → 仍要运行」（程序没有做代码签名）

**便携**：所有数据（图库、设置、窗口位置）都在 exe 旁边的 `data\` 里，把整个文件夹拷走就等于搬家，换电脑不用重新导入。

## 更多细节

- **纯本地离线**：无后端、无登录、无联网，数据全部存在你自己电脑上
- **多分类**：一张图可同时属于多个分类，「未分类」= 不属于任何分类；拖动卡片到分类 = 加入，拖到「未分类」= 从当前分类移出
- **搜索**：名称 / 拼音全拼 / 首字母，中英混合也能命中
- **拖动整理**：窗口内拖动有半透明预览和分类行高亮；拖到窗口外松手会复制到剪贴板
- **历史**：侧栏「历史」按最近复制时间倒序显示最近 50 张
- **批量管理**：点击勾选、拖动框选（切换勾选）、全选/取消全选、批量添加到分类/删除
- **导入导出**：批量导入（按内容 MD5 去重）；导出全量或单个分类为 `.zip`；导入备份恢复分类/名称/置顶/顺序（按钮或把 zip 拖进窗口）
- **外观**：三套主题（深色 / 浅色 / 樱花）、不透明度、光滑度、字体大小与自定义字体，全部重启后保持
- **窗口**：置顶 / 边缘吸附（拖动中实时贴边）/ 顶栏与侧栏空白处可拖动窗口 / 自定义颜文字标志；首次启动居中，之后记住上次位置和大小

## 数据存放位置

默认放在**软件根目录**下的 `data\`：

```
data\
├── archive.db        # SQLite 数据库（分类、命名、置顶、排序、设置）
├── emojis\           # 表情包原图（按内容 MD5 命名，平铺存放）
├── thumbs\           # 缩略图（动图取第一帧）
└── window_state.ron  # 窗口位置与大小
```

图片**不按分类建文件夹**：所有原图平铺在 `emojis/` 下、按内容 MD5 命名，分类只是数据库里的关联记录；这样改分类不用搬文件，同一张图也只存一份。

如果 exe 所在目录不可写（例如装在 `C:\Program Files`），程序会依次回退到设置里指定的目录、`%LOCALAPPDATA%\EmojiArchive`、exe 同级 `local_data`，功能不受影响。也可以在「设置 → 数据目录」里手动指定位置（重启生效，旧目录保留）。

## 配置文件

两个纯文本文件放在**软件根目录**（exe 旁边），都可以直接用记事本改，改完重启生效：

| 文件 | 作用 | 说明 |
|---|---|---|
| `kaomoji.txt` | 顶栏左上角的随机颜文字库 | 一行一个，`#` 开头的行忽略；删掉或留空则用内置默认库 |
| `welcome.txt` | 首次启动的欢迎公告（就是开头那篇） | 支持 `# 标题`、`## 副标题`、`### 小节`、`> 引言`、`- 短语：正文`、`~~删除线~~`；空行分段。**改完内容会自动让已装用户再看一次**（按内容判断，不需要手动改版本号） |

首次启动这两个文件都会自动生成模板，不想要的那份删掉即可（会回退到内置默认内容）。

## 技术栈

- 语言：**Rust**
- 界面：**egui 0.37 + eframe**（winit + wgpu 原生渲染，无 WebView）
- 存储：**SQLite**（rusqlite，bundled 编译，不依赖系统库）
- 其他：`rfd`（原生文件对话框）、`image`（GIF / PNG / JPEG / WebP 解码）、`zip` + `serde`（备份导入导出）、`pinyin`（拼音搜索）
- 平台：Windows 10 / 11（x64），单文件便携运行

## 从源码构建

需要 Rust stable（MSVC target）与 Visual Studio Build Tools 的「使用 C++ 的桌面开发」组件：

```bash
cargo build --release
# 产物：target/release/emoji-archive.exe
```

首次构建会编译 bundled SQLite，耗时几分钟；之后的增量构建很快。
